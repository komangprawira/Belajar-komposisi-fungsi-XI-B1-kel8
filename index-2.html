01 · Materi lengkap

Jelajahi dunia komposisi fungsi

Baca dari topik pertama sampai terakhir. Tekan tautan daftar materi untuk berpindah ke bagian yang kamu perlukan.

1. Mengingat kembali konsep fungsi

Fungsi adalah aturan yang memasangkan setiap anggota domain (daerah asal) dengan tepat satu anggota kodomain (daerah kawan). Nilai yang benar-benar dihasilkan disebut range (daerah hasil).

f : A → B   dan   y = f(x)

Contoh: f(x) = 2x + 1. Jika x = 3, maka f(3) = 2(3) + 1 = 7. Angka 3 merupakan masukan, sedangkan 7 merupakan keluaran fungsi.

Ingat: satu masukan tidak boleh mempunyai dua keluaran berbeda dalam satu fungsi.

2. Pengertian dan notasi komposisi fungsi

Komposisi fungsi adalah penggabungan dua fungsi atau lebih secara berurutan. Keluaran dari fungsi yang dikerjakan pertama menjadi masukan bagi fungsi berikutnya.

(f ∘ g)(x) = f(g(x))

Dibaca “f komposisi g dari x”. Fungsi g dikerjakan terlebih dahulu, kemudian hasilnya dimasukkan ke fungsi f.

Contoh

f(x) = 2x + 3 dan g(x) = x². Maka:

(f ∘ g)(x) = f(x²) = 2x² + 3.

3. Langkah menentukan komposisi dua fungsi

  1. Tulis komposisi sesuai permintaan, misalnya (f ∘ g)(x).
  2. Ubah menjadi f(g(x)).
  3. Substitusikan seluruh bentuk g(x) ke setiap x pada f(x).
  4. Gunakan tanda kurung untuk menjaga urutan operasi.
  5. Sederhanakan hasil aljabar dan periksa kembali.
Contoh lengkap

f(x) = 3x − 2 dan g(x) = x + 4. Tentukan (f ∘ g)(x).

f(g(x)) = f(x + 4)

= 3(x + 4) − 2

= 3x + 12 − 2

= 3x + 10

4. Komposisi fungsi dengan urutan berbeda

Urutan fungsi perlu diperhatikan. (f ∘ g)(x) tidak sama artinya dengan (g ∘ f)(x).

Diketahui

f(x) = 2x + 1 dan g(x) = x².

(f ∘ g)(x) = f(x²) = 2x² + 1.

(g ∘ f)(x) = g(2x + 1) = (2x + 1)² = 4x² + 4x + 1.

Karena hasilnya berbeda, komposisi fungsi pada umumnya tidak komutatif.

f ∘ g ≠ g ∘ f   (pada umumnya)

5. Sifat-sifat komposisi fungsi

a. Tidak komutatif secara umum. Menukar urutan fungsi biasanya mengubah hasil.

b. Asosiatif. Pengelompokan komposisi tiga fungsi dapat diubah tanpa mengubah urutan fungsi, selama semua komposisi terdefinisi.

f ∘ (g ∘ h) = (f ∘ g) ∘ h

c. Fungsi identitas. Fungsi identitas I(x) = x tidak mengubah nilai saat dikomposisikan.

f ∘ I = I ∘ f = f

Dengan demikian, komposisi fungsi bukan operasi penjumlahan atau perkalian fungsi; komposisi berarti memasukkan keluaran suatu fungsi ke fungsi lain.

6. Domain atau daerah asal komposisi

Domain komposisi (f ∘ g) terdiri dari nilai x yang berada pada domain g dan menghasilkan g(x) yang termasuk domain f.

Domain (f ∘ g): x ∈ Dom(g) dan g(x) ∈ Dom(f)
Contoh

f(x) = √x dan g(x) = x − 2. Maka (f ∘ g)(x) = √(x − 2).

Agar akar real terdefinisi, x − 2 ≥ 0 sehingga x ≥ 2.

Saat ada akar kuadrat, bentuk di dalam akar harus ≥ 0. Saat ada pecahan, penyebut tidak boleh 0.

7. Komposisi tiga fungsi

Untuk tiga fungsi, proses dilakukan dari fungsi paling dalam.

(f ∘ g ∘ h)(x) = f(g(h(x)))
Contoh

f(x) = x + 1, g(x) = 2x, h(x) = x².

h(x) = x²

g(h(x)) = 2x²

f(g(h(x))) = 2x² + 1

Jadi, (f ∘ g ∘ h)(x) = 2x² + 1.

8. Penerapan komposisi dalam kehidupan sehari-hari

Komposisi dapat memodelkan proses bertahap, misalnya diskon lalu biaya layanan, konversi suhu lalu penyesuaian, atau proses produksi yang melewati dua mesin.

Contoh konteks harga

Harga awal x rupiah didiskon 10%, sehingga d(x) = 0,9x. Setelah itu dikenai biaya layanan Rp5.000, yaitu b(x) = x + 5.000.

(b ∘ d)(x) = 0,9x + 5.000

Jika harga awal Rp100.000, biaya akhir = 0,9(100.000) + 5.000 = Rp95.000.

02 · Contoh soal

Contoh dan pembahasan langkah demi langkah

Pelajari cara berpikirnya, bukan hanya hasil akhirnya.

Contoh 1 · Komposisi aljabar

f(x) = 2x + 3 dan g(x) = x² − 1. Tentukan (f ∘ g)(x).

  1. (f ∘ g)(x) = f(g(x))
  2. = f(x² − 1)
  3. = 2(x² − 1) + 3
  4. = 2x² − 2 + 3
(f ∘ g)(x) = 2x² + 1

Contoh 2 · Membalik urutan

Dengan fungsi yang sama, tentukan (g ∘ f)(x).

g(f(x)) = g(2x + 3) = (2x + 3)² − 1 = 4x² + 12x + 8.

(g ∘ f)(x) = 4x² + 12x + 8

Contoh 3 · Nilai komposisi

f(x) = x − 5 dan g(x) = 3x + 2. Tentukan (f ∘ g)(4).

g(4) = 3(4) + 2 = 14, lalu f(14) = 14 − 5 = 9.

(f ∘ g)(4) = 9

Contoh 4 · Domain komposisi

f(x) = √x dan g(x) = x + 3. Tentukan (f ∘ g)(x) dan domainnya.

(f ∘ g)(x) = √(x + 3). Syarat akar: x + 3 ≥ 0, sehingga x ≥ −3.

(f ∘ g)(x) = √(x + 3), domain x ≥ −3

Contoh 5 · Fungsi dalam konteks

Bilangan x dikalikan 5, kemudian dikurangi 4. Jika f(x)=5x dan g(x)=x−4, tuliskan sebagai komposisi.

Perkalian dilakukan lebih dahulu, jadi g(f(x)) = g(5x) = 5x − 4.

(g ∘ f)(x) = 5x − 4

06 · Ringkasan

Rumus penting sebelum tes

Simpan konsep ini sebagai pengingat saat mengerjakan latihan.

ƒ

Komposisi dua fungsi

(f ∘ g)(x) = f(g(x))

Kerjakan fungsi g terlebih dahulu, kemudian f.

↔

Urutan terbalik

(g ∘ f)(x) = g(f(x))

Jangan menganggap kedua urutan selalu sama.

Ⅲ

Tiga fungsi

(f ∘ g ∘ h)(x) = f(g(h(x)))

Mulai dari fungsi paling dalam, yaitu h.

✓

Identitas dan domain

f ∘ I = I ∘ f = f

Pastikan hasil fungsi dalam memenuhi domain fungsi luar.

Checklist sebelum menjawab

  • Apakah urutan fungsi sudah benar?
  • Apakah semua x sudah diganti dengan bentuk fungsi yang tepat?
  • Apakah tanda kurung dan pangkat sudah benar?
  • Apakah domain membatasi nilai x?
